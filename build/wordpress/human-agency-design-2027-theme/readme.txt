HUMAN AGENCY DESIGN 2027 THEME

A blog-only WordPress theme based on the Human Agency Design visual system used in /build/. It provides the blog index, article, archive, search, comments, and a shared blog header/footer. It does not include portfolio, experience, AI Design Lab, or general page templates.

Install
1. In WordPress, open Appearance > Themes > Add New > Upload Theme.
2. Upload human-agency-design-2027-theme.zip and activate it.
3. In Appearance > Menus, optionally assign a menu to “Blog navigation.” Without a custom menu, the header links to the main site areas and highlights Blog.
4. Set the desired default color theme under Appearance > Customize > Human Agency Design Blog. Visitors can also choose Clear, High Contrast, Bold, or Wild from the footer.

Requires WordPress 6.0+ and PHP 7.4+.
