Stock Performance Projection Test

A small financial visualization prototype where the user enters a stock ticker, views the stock's one-year performance, and sees a basic projection for the next three months. The experiment compares how different AI platforms handle financial data, charting, forecasting, uncertainty, and responsible UX language.

How to read these

A prototype is only part of the answer.

Each result is reviewed as a design artifact and as a software artifact. I am looking for what the tool notices, what it ignores, how it explains uncertainty, and whether the interface helps someone make a better decision.

The interesting comparison is rarely just whether the code works. It is whether the generated product thinking deserves trust.
