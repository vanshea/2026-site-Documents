# Van Shea Creative Blog Revised

Version 1.6.0 of the custom Van Shea Creative WordPress theme.

## Revision highlights

- Themes now match the vanshea.com footer switcher: Clear (theme1), High Contrast (theme3), Bold (theme4, default) and Wild (theme5), using the live site's palettes. Tinted and Midnight are retired.
- Primary nav matches vanshea.com: Home, Work, Case Studies, AI Design, Experience, Blog. Background shapes removed from the blog home page.
- Uses the latest responsive footer artwork.
- Includes Schedule Time and LinkedIn footer actions.
- Makes Bold the default, like vanshea.com, while preserving visitor and Customizer preferences.
- Keeps the header logo theme-driven so Clear uses the dark mark.
- Bundles the updated dark and light logo marks inside the theme.
- Retains featured-image repair support for imported posts.

## Requirements

- WordPress 6.0 or newer
- PHP 7.4 or newer

Activate **Van Shea Creative Blog Revised** from Appearance > Themes.
