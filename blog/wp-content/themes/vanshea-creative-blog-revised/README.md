# Van Shea Creative Blog Revised

Version 1.4.0 of the custom Van Shea Creative WordPress theme.

## Revision highlights

- Uses the latest responsive footer artwork.
- Includes Schedule Time and LinkedIn footer actions.
- Matches the main site theme names: Basic Theme, Pro Theme, High Contrast, and Wild Theme.
- Makes Wild Theme the default while preserving visitor and Customizer preferences.
- Uses the updated light logo asset for dark color-scheme preferences.
- Retains featured-image repair support for imported posts.

## Requirements

- WordPress 6.0 or newer
- PHP 7.4 or newer

Activate **Van Shea Creative Blog Revised** from Appearance > Themes.
