VAN SHEA CREATIVE — WORDPRESS THEME

Installation
1. In WordPress, open Appearance > Themes > Add New > Upload Theme.
2. Upload van-shea-creative-wordpress-theme.zip and activate it.
3. Set the homepage display to “Your latest posts” (the theme front-page template is used automatically).
4. Create Pages with these slugs for the homepage navigation: work, case-studies, ai-design, experience. Add the case study pages under case-studies with the matching slugs. WordPress page content is managed separately from the theme.
5. Optional: create and assign a Primary navigation menu under Appearance > Menus.

The front page, typography, color themes, recommendation carousel, AI Design Lab interactive prototypes, and footer wave are based on the current /build/ design. The theme package includes required images, icons, and prototype files. It does not import the site's existing inner-page copy as WordPress content; add or migrate those pages after installation.
